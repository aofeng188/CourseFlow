# 课序使用说明

适用于当前开发版本。底部有「课表」「课程」「设置」三个页面；可先在欢迎页点「先体验示例课表」。示例是独立学期，使用自己的资料时可另外新建学期。

## 1. 先设置学期与学校作息

1. 欢迎页点「设置我的第一个学期」，填写学期名称、「第 1 周的周一」、总周数和学校时区，点「保存」。已知今天是第几教学周时，可用「根据今天校准开学日期」。后续从「设置」→「学期设置」修改。
2. 如果课表只有“第 1–2 节”等节次，先打开「设置」→「添加作息方案」。填写生效日期，用「生成节次时间」生成初稿，再逐节调整午休、晚课和课间，最后点「确认保存」。
3. 也可以点首页右上角「＋」→「导入课表或作息」，将「导入内容」切换为「学校作息表」，导入官方图片、PDF 或表格，逐节核对后点「确认学校作息」。

学期单双周按学校教学周计算。冬夏作息可保存为生效日期不同的方案；导入的作息默认从学期首日生效，可在设置中调整。课程若直接使用具体起止时间，则不需要节次映射。

## 2. 导入并核对课表

进入「＋」→「导入课表或作息」，选择「课程表」。工程的 [Fixtures](../Fixtures) 文件夹提供可练习的资料；先将文件放到设备「文件」App 可选择的位置，图片也可存入照片。

| 来源 | 界面操作 | 可用示例 |
| --- | --- | --- |
| 其他 AI 的识别结果 | 「AI 文本导入」→「复制提示词」→将提示词和图片交给 AI→粘贴返回内容→「核对内容」 | [操作说明及 JSON 样本](AI-IMPORT.md) |
| 图片或截图 | 「照片与截图」，或通过文件选择图片；添加后点「识别 N 张待处理图片」 | [示例课程与作息.png](../Fixtures/示例课程与作息.png) |
| PDF | 「文件 · PDF / Excel / CSV」→选文件→「选择 PDF 页面」→「添加」，再识别待处理页面 | [示例课程与作息.pdf](../Fixtures/示例课程与作息.pdf) |
| Excel | 选择 `.xlsx`，在「核对表格格式」中选工作表和排列方式，再点「识别」 | [示例课表.xlsx](../Fixtures/示例课表.xlsx) |
| CSV/TSV | 选择文件，核对表头和对应字段，再点「识别」 | [示例课表.csv](../Fixtures/示例课表.csv)、[示例作息.tsv](../Fixtures/示例作息.tsv) |
| 文字 | 「粘贴文字」→保留原文换行→「识别」 | 例如 `高等数学 星期一 08:00-09:40 1-8周 主楼A301` |

示例 CSV 的课程使用学校节次，可先将示例 TSV 作为「学校作息表」导入。Excel 的课程清单选「每行一门课」；横向星期、纵向节次的课表选「星期 × 节次网格」。旧版 `.xls` 需先另存为 `.xlsx` 或 CSV。

在「待核对课程」点课程或「编辑」，补齐名称、星期、时间、周次、地点和教师。点原件缩略图可放大对照，缩略图菜单提供「裁剪与旋转」；裁剪后需重新识别。缺作息时可关闭草稿，先去补充作息再继续。

只勾选要保存的条目；相同地点或周次可用「批量修改选中课程」，不同周次去不同教室可用「复制后拆分」。确认按钮不可用时，展开「需要核对 N 项」，修正缺失信息；如确实要保留时间重叠，核对后再开启「我已核对上述重叠安排，仍要导入」。

最后选择「跳过已有课程」或「更新已有课程资料」，点「核对完成，确认导入」。确认前只是草稿；部分导入后，未选课程、待识别图片和所需原件会继续保留。「关闭」可下次继续，「清空本次导入」会删除该次草稿和 App 内原件副本。

## 3. 精细编辑周次与单次调整

在「课程」页或周课表中点开课程，进入「编辑全部安排」。一门课可以有多条上课安排，各自设置星期、节次/具体时间、地点和教师。已有地点和教师可从历史按钮复用。

「课程资料」里的「课程头像」可选「首字」（默认）、「文字」（一两个字或表情）、「图标」或「照片」。照片会裁成正方形并缩小后随课程保存，包含在备份和 iCloud 同步中。

在「上课安排」的「上课周数」输入 `1-8`、`1-8,10-16` 或 `1-16周(单)，排除7周`，点「应用」；也可逐周点选。返回课程页后再点「保存」，修改才生效。

从某个具体课次进入「调整课程」时，按需要选择：

- 「仅本次：时间或地点」：只调整所选日期的一次课。
- 「从本次起：后续安排」：修改该条安排从本周起的课程，保留之前的周次和单次调整。额外补课、整日调休课不提供此方式。
- 「全部安排」：编辑这门课的重复安排、名称、颜色和提醒设置。

临时不上课用「本次停课」→「确认本次停课」。恢复时从「课程」页进入该课程，在「单次调整记录」的菜单点「恢复本次上课」；调课可「撤销这次调课」，补课可「移除这次补课」。恢复后若出现冲突，先检查提示。

学校整日换课从「设置」→「学校调休 / 整日换课」选择目标日和来源日，先「预览调整后的课程」，再「确认应用调休」。目标日会按来源日对应的周次和星期上课，来源日自身保留。

## 4. 日历与上课提醒

在「设置」开启「上课提醒」并允许系统通知，选择「默认提前」。单门课程的「上课提醒」可以跟随全局、不提醒或单独设定提前时间。连堂安排只在第一节前提醒一次。设置页显示系统已排提醒数量和覆盖截止日期；当前最多安排最近 60 条，长期不打开 App 时，后台补排没有固定执行保证。

需要把整个学期交给系统日历：打开「添加到日历与同步」→「允许日历访问」，允许完整访问，检查「同步预览」后点「同步到系统日历」。课序会使用独立学期日历；同一课次重复同步不重复添加。课表改动会在负责设备执行刷新/同步后更新，系统日历中手改的内容会保留并列出。

默认只在日历时间和提醒提前量都与课表一致时，避免重复的 App 提醒；确需两种提醒同时出现，可开启「同时使用 App 和日历提醒」。系统专注模式、权限和日历账户设置仍会影响提醒呈现。

多设备使用时，每个学期由一台设备负责写日历。换设备前，在旧设备点「暂停本设备日历自动同步」，在新设备点「在本设备接管日历同步」并核对已有事件，等其他设备联网更新负责人。

**删除学期前，先处理已导出的日历。** 在对应学期点「添加到日历与同步」→「移除本学期已导出的课程」→「移除课程」，然后再删除学期。手改事件会保留，需在系统日历中自行处理。删除学期时若选「保留日历并删除学期」，旧日历提醒仍会继续。

## 5. 查看、分享与备份

首页顶部显示当前上课、课间或下一门课；连堂课的进度条按节分段，覆盖整次课，并标出当前是第几节、距全部下课还有多久；周选择器可切换教学周。课表右上角菜单可切换「显示日程列表」，或「分享本周图片」「分享本周 PDF」。小组件和「课程实况活动」使用当前选中的学期；实况活动预约启动会产生系统提示。

「设置」→「导出完整备份」生成 `.courseflow` 文件；恢复时选「从备份恢复」，检查学期和课程数量，再点「备份当前资料并恢复」。恢复前会自动保存一份当前资料。备份不含导入原件、API Key 或通知队列，恢复后需重新核对日历负责人和提醒设置。

「导出学期日历文件 (.ics)」适合手动分享或导入其他日历软件；文件导出与 App 内日历同步是分开的流程，不会自动更新收件人已导入的副本。

## 6. 可选的自配云端识别（BYOK）

普通识别在设备上完成。需要云端增强时，从「设置」→「识别增强设置」填写服务商提供的 HTTPS API 地址、模型名称和自己的 API Key，点「保存配置」。服务需要兼容 OpenAI Chat Completions 格式。

回到导入核对页选择「使用自配云端模型…」，查看目标服务和待发送文字，点「确认并发送本次内容」才会上传。默认只上传文字；仅在开启「一并上传所选原图」后才发送图片。模型结果仍需核对后确认导入，也可「撤销上次智能整理」。

密钥保存在本机 Keychain，可在配置页点「删除此服务的密钥」；服务商收费与数据保留按其条款处理。没有密钥或本机 Apple Intelligence 不可用时，仍可使用普通识别和手动核对。更多数据处理说明见 [隐私说明](PRIVACY.md)。
