# 课序隐私与数据处理说明

更新日期：2026-09-11。本文描述当前工程的实际数据流程，供开发与验收使用；正式发布前应补充发布主体、联系渠道和最终服务配置。

## 默认在设备上处理

课序没有自建账户系统，不接入广告或行为分析 SDK。课程、教学周、教室、教师、作息时间与调课资料保存在 App 的 SwiftData 数据库中。导入草稿、原件副本和图片处理结果保存在 App 的本机沙盒中，普通识别使用 Vision；可用的本机模型增强使用系统 Foundation Models。

选择照片或文件，仅会读取用户通过系统选择器选中的内容；相机用于用户主动扫描。课序不会在没有导入操作的情况下扫描整个照片库或文件系统。

导入资料可能包含姓名、学号、班级或其他个人信息。核对页可以查看并编辑识别文字，移除不需要的原件，再决定是否保存课程或上传增强识别。

「AI 文本导入」仅在本机解析你粘贴的 JSON，不调用模型服务，也不需要 API Key。复制或分享提示词由你主动操作；图片是否发送给其他 AI，由你在那个工具中决定。未处理的粘贴内容与解析后的原文保存在本机导入草稿中，可通过「清空本次导入」删除，不进入课表 iCloud 同步或默认备份。

## 可选云端识别：自己提供服务与密钥

云端识别默认不运行。用户需要配置 HTTPS API 地址、模型和自己的 API Key，并在导入核对页主动选择云端识别、确认目标服务商与发送内容后，App 才发起请求。

- 默认只发送本次提取的文字与必要的识别提示。
- 只有开启「一并上传所选原图」并确认后，才将所选图片作为该请求的一部分发送；接收方需要支持图像输入。
- API Key 保存在本机 Keychain 中，使用仅限此设备的可访问性设置，不随课表 CloudKit 同步。请求时通过 Authorization 头发送给用户配置的服务。
- 请求使用临时 URLSession，并拒绝 HTTP 重定向，避免把授权头转发到另一个地址。
- 服务商可能收费、保存请求或按其条款处理数据。课序无法替用户删除已经发送到第三方服务器的数据；应向对应服务商管理这些记录。

云端识别设置提供删除当前服务密钥的操作。更换服务地址不会自动把旧密钥发送给新服务；管理旧服务密钥时应切回原服务地址进行删除。

## 可选 iCloud、日历、小组件与通知

CloudKit 同步默认关闭。开发者配置签名和 `iCloud.com.courseflow.app` 容器，并将 `COURSEFLOW_ICLOUD_ENABLED` 设为 `YES` 后，课表领域资料会通过用户的私有 CloudKit 数据库同步。导入原件、导入草稿、第三方 API Key、日历事件映射和设备身份不加入这套课表同步。

App Group 中会保存一份供小组件读取的课表快照。开启提醒或实况活动后，课程名称、时间和地点可能显示在锁屏、通知中心与灵动岛；显示方式仍受用户的系统设置控制。

系统日历功能仅在用户选择该功能后请求完整日历访问。完整权限用于核对 App 自己添加的事件、更新和删除课程、防止重复；App 使用所有权标记与本地记录限制修改范围。专属课表日历所在的系统账户可能由 iCloud、Exchange 或其他日历提供方同步，按该账户的设置处理。

每个学期的日历写入负责人使用本机生成的随机身份，不读取硬件序列号。身份保存在不参与 iCloud 同步的本机 Keychain，日历映射记录保存在本机并排除常规文件备份。

## 删除与保留

- 导入核对页可移除所选图片及其 App 内原件副本，或清除整个导入草稿。仅保存部分课程时，未选条目、待识别图片和继续核对所需的原件仍保留在本机草稿；所有条目处理完成或用户清空后，才清理该次全部来源。保存失败或取消确认时保留草稿。删除 App 副本不会删除照片库中的原照片、用户的源文件或源云盘文件。
- 已保存的课程可以在课程编辑中删除。开启 CloudKit 时，删除状态会参与同步，以免旧设备重新带回已删除资料。
- 已添加到系统日历的课程需要在日历设置页使用「移除本学期已导出的课程」，或直接在系统日历中管理。为保护用户手改内容，App 不会自动删除已经被手动修改的事件。
- `.courseflow` 和 ICS 文件通过用户主动导出保存。备份恢复前产生的本机备份，以及已经分享到其他位置的文件，是独立副本，用户需要分别管理。
- 删除本机 Keychain 中的第三方 API Key 可在云端识别设置完成。系统对卸载后 Keychain、iCloud 资料和日历数据的保留独立于 App；卸载不是清除所有外部副本的保证。

“本地处理”描述 App 自身的数据路径。iOS 的整机备份、照片云同步、文件提供商与日历账户可能按用户的系统设置保存副本，这些由对应系统服务管理。
