# 用其他 AI 整理课表，再粘贴回课序

「AI 文本导入」提供课序能读取的提示词：你把提示词和课表图片交给自己使用的 AI，再把它返回的 JSON 粘贴回课序。课序在本机解析并生成可编辑草稿，核对后才保存课程。此方式无需在课序设置 API Key，课序也不会为此发起网络请求；图片是否发送给其他 AI 由你在那个工具中决定。

## 操作流程

1. 先在课序创建学期，确认第 1 周的周一、总周数和学校时区。
2. 打开「导入课表或作息」，选择「课程表」或「学校作息表」，进入「AI 文本导入」。
3. 点「复制提示词」，把它粘贴到支持图片理解的 AI 对话工具，并附上要识别的图片或文件。多页课表可以一起提供，边缘的星期、周次说明和表头也要保留。
4. 让 AI 按提示词返回 JSON。复制完整结果，回到课序粘贴，生成待核对草稿。
5. 对照原件核对课程名、星期、周次、节次或具体时间、地点及教师。缺失的信息手动补齐；无需导入的条目取消勾选。原件未提供的信息不应让 AI 猜测。
6. 核对无误后点「核对完成，确认导入」；作息草稿则逐节核对后点「确认学校作息」。此时才会进入正式课表，并按你的设置刷新提醒或日历。

课表只有「第几节」时，需要关联**已经确认的学校作息表**。可以先把学校官方作息图片用同一入口导入，再导入课表。两种资料的提示词和结果类型不同，不要把作息节次混进课程表结果里。

提示词以 App 内复制的版本为准；也可以直接打开完整的 [AI 课表识别提示词](../Fixtures/AI课表识别提示词.txt) 或 [AI 作息识别提示词](../Fixtures/AI作息识别提示词.txt) 复制使用。独立文件默认以 **20 周**作为校验范围，不能用来补全原件缺失的周次；App 中复制时会使用当前学期的实际周数。

两份文件由 [导出脚本](../Scripts/export_ai_prompts.swift) 调用 [AIImportFormat.swift](../Shared/Core/AIImportFormat.swift) 中的同一提示词实现生成，不手动维护第二份文字。修改源代码后，从工程根目录重新导出：

```sh
DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer \
  xcrun swiftc -parse-as-library Shared/Core/*.swift Scripts/export_ai_prompts.swift \
  -o /tmp/courseflow-export-ai-prompts
/tmp/courseflow-export-ai-prompts Fixtures
```

运行时可替换最后的输出目录；不传参数默认写入 `Fixtures/`。

## 可直接练习的样本

- [课表 JSON](../Fixtures/ai-timetable.json)：包含同一课程不同星期和教室、连续及离散周、单双周，以及一条故意保留缺失字段的课程。
- [作息 JSON](../Fixtures/ai-bell-schedule.json)：8 节课，含课间和午休。

这些是虚构数据。原样练习时使用至少 16 周的学期，先导入作息，再导入课表；课表中的「大学英语」需补齐星期、周次和时间，或取消勾选后先保存其他课程。

下面这段可以直接复制到「AI 文本导入」练习。它使用具体时间，不需要节次作息：

```json
{
  "format": "courseflow.ai",
  "version": 1,
  "kind": "timetable",
  "sourceName": "格式练习",
  "lessons": [
    {
      "name": "高等数学",
      "weekday": 1,
      "weeks": "1-8",
      "periods": null,
      "start": "08:00",
      "end": "09:40",
      "location": "主楼 A301",
      "teacher": null,
      "source": "高等数学 周一 08:00-09:40 1-8周 主楼A301",
      "warnings": []
    }
  ],
  "periods": [],
  "warnings": []
}
```

## 格式要点

| 字段 | 填写规则 |
| --- | --- |
| `format` / `version` | 固定为 `"courseflow.ai"` 和数字 `1` |
| `kind` | 课程表为 `"timetable"`；作息表为 `"bellSchedule"` |
| `sourceName` | 本次资料名称 |
| `lessons` | 课程安排数组；作息表必须是空数组 `[]` |
| 顶层 `periods` | 作息的节次时间数组；课程表必须是空数组 `[]` |
| `warnings` | 需要核对的说明数组；没有说明时填 `[]` |
| 课程的 `weekday` | 周一至周日分别用数字 `1` 至 `7`；看不清时填 `null` |
| 课程的 `weeks` | 周次字符串，例如 `"1-8"`、`"1-8,10-16"`、`"1-16周(单)，排除7周"`；缺失时填 `null` |
| 课程的 `periods` | 节次字符串，例如 `"1-2"`；课程使用具体时间时可填 `null` |
| 课程的 `start` / `end` | 24 小时制 `"HH:mm"` 字符串；原件只有节次时填 `null`，不要自行换算学校时间 |
| `location` / `teacher` / `source` | 地点、教师和对应原文；缺失可填 `null` |
| 作息的 `number` / `start` / `end` | 数字节次及该节起止时间，例如 `{"number":1,"start":"08:00","end":"08:45"}` |

同一课程有不同星期、周次、地点或教师时，应生成多条安排；同一个格子包含多门课时也要拆开。缺星期、周次或时间的课程可以保留在草稿里继续编辑，不会自动补成「周一」「全学期」或常见上课时间。

## 结果无法解析时

确认复制的是完整 JSON，保留最外层 `{}`，不要改成 Markdown 课表、自然语言或截图。`null` 不能写成字符串 `"null"`，星期和版本使用数字，字段名称使用提示词规定的英文名称。课程表和作息表的 `kind` 要与当前导入内容相同。

格式错误时先在粘贴页修正，或让原 AI 按原提示词重新输出；已有课表不会因此被覆盖。JSON 能解析也不代表内容正确，最终仍以你核对的学校资料为准。
